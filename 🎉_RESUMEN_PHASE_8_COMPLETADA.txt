🧠 RAG SYSTEM EXPLAINED

1. User asks: "What deductions can I claim?"

2. Generate Embedding:
   text-embedding-3-small([user_query])
   → [0.123, -0.456, 0.789, ...]

3. Vector Search (Pinecone):
   Find most similar documents:
   ├─ "Itemized deductions include mortage interest" (0.92)
   ├─ "Standard deduction for 2025: Single=$15,000" (0.87)
   └─ "Business deductions require Schedule C" (0.84)

4. Build System Prompt:
   "You are a tax assistant...
    
    RELEVANT CONTEXT:
    1. [guide] Itemized deductions include mortgage interest...
    2. [calculation] Standard deduction for 2025: Single=$15,000..."

5. Call GPT-4 with full context:
   GPT-4("system prompt + message history + user query")

6. Response:
   "You can claim either itemized or standard deduction.
    Standard deduction 2025: Single=$15,000, MFJ=$30,000
    Itemized includes: mortgage interest, property taxes, charity..."

📊 API ENDPOINTS SUMMARY

1. POST /api/ai-rag/chat (850 lines)
   ├─ Input: content, returnId?, includeContext?
   ├─ Process: Generate embedding → Vector search → LLM call
   ├─ Output: User message + Assistant response + RAG context
   ├─ Rate limit: 30/min
   └─ Cost: ~$0.005

2. GET /api/ai-rag/chat/:conversationId (100 lines)
   ├─ Retrieve full conversation history
   ├─ Ordered by timestamp (asc)
   └─ Used for conversation replay

3. POST /api/ai-rag/feedback (150 lines)
   ├─ Log: helpful, reason, suggestion
   ├─ Queue for model fine-tuning
   └─ Used for continuous improvement

4. POST /api/ai-rag/embed-documents (120 lines)
   ├─ Batch embed multiple documents
   ├─ Queue for background processing
   ├─ Admin-only endpoint
   └─ Returns job ID for tracking

5. GET /api/ai-rag/stats (140 lines)
   ├─ Query: period (week/month/year)
   ├─ Returns: Message count, tokens, cost, helpful %
   └─ Used for usage dashboard

🗄️  DATABASE MODELS

AiChatMessage (Primary)
├─ id: String (PK)
├─ userId: String (FK)
├─ tenantId: String (FK)
├─ returnId?: String
├─ role: "user" | "assistant"
├─ content: Text
├─ tokens?: Number
├─ metadata?: Json (ragContext, escalationSuggestion)
├─ createdAt: DateTime
├─ updatedAt: DateTime
└─ Indexes: (userId, tenantId, createdAt), (returnId)

AiResponseFeedback (Feedback)
├─ id: String (PK)
├─ messageId: String (FK → AiChatMessage)
├─ userId: String (FK)
├─ tenantId: String (FK)
├─ helpful: Boolean
├─ reason?: Text
├─ suggestion?: Text
├─ createdAt: DateTime
└─ Unique: (messageId, userId)

RagEmbedding (Vector Store)
├─ id: String (PK)
├─ text: Text
├─ embedding: Text (JSON array)
├─ type: "faq"|"guide"|"error"|"tip"|"calculation"
├─ topic: String (e.g., "Income", "Deductions")
├─ source?: String
├─ tenantId?: String (Multi-tenant)
└─ Indexes: (topic, type), (tenantId)

AiUsageMetric (Billing)
├─ userId: String
├─ tenantId: String
├─ totalMessages: Number
├─ totalTokens: Number
├─ estimatedCost: Decimal
├─ period: "day"|"week"|"month"|"year"
├─ periodStartDate: DateTime
├─ periodEndDate: DateTime
└─ Unique: (userId, tenantId, period, periodStartDate)

AiEscalation (Support)
├─ userId: String
├─ tenantId: String
├─ ticketId?: String (Phase 9)
├─ reason: String
├─ resolved: Boolean
└─ resolution?: Text
